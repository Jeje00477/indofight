# Audio IndoFight

## Efek suara (SFX)

Dibuat dengan skill ElevenLabs `sound-effects` (`npx skills add https://github.com/elevenlabs/skills --skill sound-effects`). Simpan sebagai WAV atau OGG di `audio/sfx/`. Buat 2 sampai 3 variasi untuk pukulan supaya tidak terdengar berulang.

| Kode | Isi | Durasi (detik) | Prompt |
| --- | --- | --- | --- |
| `sfx_hit_light` | Pukulan ringan | 0.5 | a quick light punch impact, short punchy thwack, video game fighting sound |

## Musik (brief untuk komposer)

Gaya: Gamelan Cyberpunk, yaitu gamelan Jawa atau Bali digabung EDM atau rock. Tempo 140 sampai 170 BPM untuk pertarungan. Setiap lagu harus bisa diputar berulang tanpa jeda terasa.

| Lagu | Suasana |
| --- | --- |
| Main Menu | megah, mengundang, gong dan synth |
| Character Select | tegang, berulang pendek |
| Depan Gedung DPR | rock keras, drum demo |
| Lobi Istana / Kemenhan | marching band elektronik, megah |
| Candi Prambanan Malam | gamelan mistis, sub bass gelap |
| Gang Sempit | dangdut koplo elektronik |
| Proyek Mangkrak | industrial, suara besi dipukul |
| Warnet Berkah | chiptune cepat |

Musik sebaiknya dibuat komposer atau memakai musik berlisensi, karena musik adalah identitas utama game ini. Catat semua lisensi di `docs/credits.md`.
